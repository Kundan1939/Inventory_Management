Remote Hardware Discovery Agent (macOS, Linux & Windows)

Run a 1-line command on any remote laptop or desktop. The agent automatically queries Motherboard/Logic Board, Processor, RAM, physical SSD/NVMe drives, Serial Number, Device Hostname, and logged-in User Name, storing them straight into this database:

macOS (MacBook, Mac mini, Mac Studio, iMac)
curl -sSL {{ lan_url }}/agent.sh | bash
Linux / Ubuntu (Laptops & Desktops)
curl -sSL {{ lan_url }}/agent.sh | sudo bash
Windows (PowerShell — Native Zero Install)
irm {{ lan_url }}/agent.ps1 | iex
Optional override flags: --assigned "Employee Name" --department "Engineering" --location "Office 2"
System Environment & Storage
Database Engine SQLite 3 (Transactional WAL)
Database File data/assets.db
AI Engine Zero-API Offline Heuristic + Wiki
OCR Engine RapidOCR (ONNX Runtime)
Barcode Engine zxing-cpp + Html5Qrcode

Remote Device Auto-Discovery Agent

Run a single command on any laptop or desktop (Ubuntu/Linux or Windows) on your network. It extracts Motherboard, Processor, RAM, physical SSD/NVMe drives, Serial Number, Device Name, and User Name, and directly registers the asset into this database:

Target Server: {{ lan_url }}
macOS (MacBook, Mac mini, Mac Studio, iMac)
curl -sSL {{ lan_url }}/agent.sh | bash
Linux / Ubuntu (Laptops & Desktops)
curl -sSL {{ lan_url }}/agent.sh | sudo bash
Windows (Laptops & Desktops — PowerShell)
irm {{ lan_url }}/agent.ps1 | iex
Zero Setup: The agent automatically identifies Motherboard, CPU Cores/Threads, Normalized RAM, Physical SSD models, Serial Tag, Device Hostname, and logged-in User Name.
